# پیش‌نمایش مرورگری «سه توپ» (آینهٔ main.gd v2.1)

> ⚠️ این یک **آینهٔ مرورگری** از قوانین و حس بازی است، نه اجرای موتور Godot.
> نسخهٔ اصلی یک پروژهٔ Godot 4.7 است. چون باینری موتور در این محیط قابل اجرا نبود،
> ثابت‌ها، هندسه، فیزیک و منطق داوری `main.gd` عیناً به Canvas/JS منتقل شد تا بازی
> بدون Godot هم واقعاً بازی‌شدنی و تست‌پذیر باشد.

## اجرا

```bash
cd preview && python3 -m http.server 8080 --bind 0.0.0.0
```

بعد آدرس پیش‌نمایش را باز کنید. با **کشیدن توپ و رها کردن** شوت می‌زنید.
کلیدهای **۱ / ۲ / ۳** پریست‌های تعادل را عوض می‌کنند.

## چه چیزی در نسخهٔ ۲.۱ اصلاح شد

نسخهٔ Phase 2 **غیرقابل‌بردن** بود. سه مانع مستقل پیدا و رفع شد:

**۱) ترتیب داوری (باگ کشنده)**
`_evaluate_shot()` قبل از باز کردن دروازه، `passed_between` را بررسی و `return` می‌کرد.
چون خط هجوم از محل شروع توپ‌ها بالاتر است، همان شوتی که باید دروازه را باز کند
«سوختی» می‌گرفت. در نسخهٔ ۲.۱ داوری بازنویسی شد: ابتدا دستاوردها (گل/پاس/بازکننده)
ثبت می‌شوند و تنها اگر هیچ‌کدام نبود خطا اعلام می‌شود.

**۲) هندسه — «شوت طلایی» ریاضیاً ناممکن بود**
عبور از شکاف پاس حرکت جانبی می‌خواهد و رسیدن به خط هجوم حرکت عمودی. با
`ATTACK_LINE_Y = 720` هیچ شوتی نمی‌توانست هر دو را انجام دهد. با جستجوی عددی روی
۲۱۶۰ شوت، خط هجوم روی **۶۲٪** ارتفاع میز تنظیم شد تا شوتِ موربِ پاس از خط هم بگذرد.

**۳) شوت‌ها از میز بیرون می‌رفتند**
حداکثر مسافت یک شوت ۱۶۰۰px بود ولی میز فقط ۱۵۴۲px ارتفاع دارد؛ هر شوت پرسرعت
«بیرون افتاد» می‌شد. دیواره‌های فیزیکی دور میز (با دهانهٔ دروازه) اضافه شد.

با این تنظیم‌ها و شبیه‌سازی کامل، مسابقه تا ۳ گل و **MATCH_OVER** می‌رسد.
