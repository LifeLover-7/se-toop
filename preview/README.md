# پیش‌نمایش مرورگری «سه‌توپ»

این نسخهٔ قابل‌بازی در مرورگر، همراه با پروژهٔ اصلی Godot 4.7 نگه‌داری می‌شود؛ جایگزین پروژهٔ Godot نیست. کد آن، قوانین و تنظیمات بازی را برای تست سریع در مرورگر بازسازی می‌کند.

## اجرا

```bash
cd preview && python3 -m http.server 8080 --bind 0.0.0.0
```

منوی اصلی با نشان اختصاصی و پنل‌های تنظیم طراحی شده و امکان تنظیم حرکت هر نوبت از ۱ تا ۹ و انتخاب حالت حرفه‌ای را می‌دهد. آموزش فقط بار اول نمایش داده می‌شود و نمونهٔ خط نشانه‌گیری در خود آموزش همیشه دیده می‌شود؛ در حالت حرفه‌ای خطوط بازی هنگام هدف‌گیری مخفی‌اند. اسکوربورد درشت‌تر و کارتی است. کلیدهای ۱، ۲ و ۳ پریست‌های تعادل را عوض می‌کنند؛ Escape یا دکمهٔ «منو» منو را باز می‌کند.

صفحه در حالت عمودی و افقی قابل‌بازی است؛ در حالت افقی میز می‌چرخد و ورودی لمس/ماوس نیز با چرخش هماهنگ است.

## قوانین فعلی

- پاس از شکاف بین دو توپ دیگر، حرکت موفق است؛ برخورد با توپ دیگر خطاست و نوبت را می‌سوزاند؛ حرکت توپ پس از برخورد ادامه دارد.
- با عبور یکی از توپ‌ها از خطی عقب‌تر از نیمه (نسبت ۴۷٪)، مسیر دروازه آزاد می‌شود؛ توپ‌ها ابتدای هر نوبت از چیدمان متغیر فرود می‌آیند و پخش می‌شوند.
- گل فقط وقتی ثبت می‌شود که تمام توپ از خط ورودی دروازه عبور کند.
- پیش‌فرض حرکت هر نوبت ۳ است و از منو قابل تنظیم است.

## محدودیت‌ها

این پیش‌نمایش از فیزیک ساده‌شدهٔ JavaScript استفاده می‌کند؛ مسیرها ممکن است با برخوردهای Godot `RigidBody2D` کمی فرق کنند. انیمیشن‌ها و صدا نیز تقریب هستند، نه اجرای موتور Godot.
